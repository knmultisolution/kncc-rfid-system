# KNCC RFID System – Update 2026-10-06

## Data-only RFID scan mode
- ESP32 sends UID + RC522 diagnostic data to `/api/device/scan`.
- Server keeps the signal profile/fingerprint for history.
- Server does **not** reject a registered active card because of signal mismatch.
- A registered active card creates/updates attendance normally.
- Every physical scan is stored in `attendance_scan_events`.
- An unknown/unassigned/disabled card is stored as a scan event but cannot create student attendance until assigned.
